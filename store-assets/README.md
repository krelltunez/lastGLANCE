# Store assets

Marketing assets for the App Store and Google Play listings. Nothing here is
used by the app build.

lifeGLANCE calls its equivalent `play-assets/`; this one is `store-assets/`
because lastGLANCE ships to two stores and the Apple set is not interchangeable
with the Play set (different canvases, and Apple's metadata rules forbid naming
Android anywhere in the listing).

## What is committed

The screenshots below are **the set that was uploaded to the stores**, so a
regeneration can be diffed against what customers actually saw rather than
against nothing.

```
apple/iphone-dynamic-island-medium/  5 frames  1206 x 2622  "iPhone with Dynamic Island
                                                             (medium display)"
apple/ipad-13/                       2 frames  2064 x 2752  iPad 13" slot
play/phone/                          5 frames  1320 x 2640  Play phone (exactly Play's 2:1 cap)
play/tablet/                         2 frames  2064 x 2752  Play tablet slot
```

**Apple retired the 6.9-inch tab (2026-10).** The iPhone galleries are now
"iPhone with Dynamic Island (medium display)", which takes 1179 x 2556 or
1206 x 2622, and "iPhone Duo". The frames here are the larger of the two
accepted sizes. The kit renders at 1320 x 2868, which no longer fits any slot,
so **a regenerated iPhone frame has to be rescaled before upload** — see below.
Play's slots are unchanged.

Order is the upload order: dashboard, completion history, People, cadence,
overdue nudge. People sits third deliberately, so a customer scrolling the
gallery learns the app is two things without having to scroll far.

The tablet frames hold a **landscape device inside a portrait canvas**. That is
intentional: the canvas has to stay 2064 x 2752 to drop into the same store slot
as a portrait frame, while a three-column masonry wants landscape.

The Play feature graphic is not here. It lives at `public/brand/feature-graphic.png`
and is generated by `scripts/feature-graphic/` (see that folder's README).

## Regenerating

There is **no `npm run screenshots` in this repo**. Unlike lifeGLANCE, the
pipeline is not committed: the frames are built with the **dayGLANCE / GLANCE
Apps screenshot kit** (v2.1, October 2026), which carries the device chrome
donors, the fonts and the framer scripts. Ask the maintainer for the kit zip;
its README is the authority on everything below.

Two things that kit's README will not tell you, because they are this app's:

- **Brand colour.** The framers hold dayGLANCE orange in a module-level
  `ORANGE` they read at call time. Set `mod.ORANGE = (61, 220, 132)` —
  lastGLANCE green `#3DDC84` — on each framer module before rendering. No
  forked framers needed.
- **Chrome tones.** The framers default their grafted status bars to
  dayGLANCE's header `(31,41,55)`, which reads as a lighter stripe across this
  app's much darker chrome. Pass lastGLANCE's own, sampled from the renders:
  `(2,6,23)` on a normal screen; on a screen with a modal open, `(0,2,9)` at the
  top (the dimmed backdrop) and `(41,53,72)` at the bottom (the modal's footer).

Content renders go in at the kit's **content-area** ratios, never the screen
ratio. For this app those were:

| device | content render | CSS viewport |
| --- | --- | --- |
| iPhone | 1600 x 3084 | 400 x 771 @ dsf 4 |
| Pixel | 1600 x 3220 | 400 x 805 @ dsf 4 |
| tablets | 2752 x 2064 | 1376 x 1032 @ dsf 2 |

Both phone widths round to exactly the framer's screen width (950 and 1080), so
no frame needs edge extension. Check that arithmetic before rendering a new
size, not after.

**Then rescale the iPhone frames**, because the kit's framer emits 1320 x 2868
and Apple no longer has a slot that size:

```python
from PIL import Image
Image.open(frame).resize((1206, 2622), Image.LANCZOS).save(frame, optimize=True)
```

Rescaled rather than re-rendered on purpose. The framer's layout constants
(`device_top`, `body_w`, the margins, the type sizes) are absolute pixels tuned
for a 1320-wide canvas, so re-tuning them for 1206 is the same arithmetic as
scaling the finished frame by 1206/1320, with the layout risk added back. The
aspect ratios differ by 0.065%, which is under two pixels across the height.

The other accepted size, 1179 x 2556, is 0.220% off instead; switching to it is
the same one-liner.

## Demo data

The shots are **not** built from `public/demo-backup.json`. That fixture's
newest completion is from May 2026, so everything in it reads as months overdue,
and several of its icon names no longer resolve. The screenshot data is
generated fresh and dated relative to the run, with a colour spread chosen so
one screen shows green, amber and red honestly.

Two constraints any regeneration must keep:

- **No medical content.** The listing declares a 4+ age rating, and Apple's
  questionnaire asks about medical and treatment information. An earlier set put
  a Health > Medical group front and centre (dentist cleaning, annual physical,
  eye exam, take vitamins). Health now holds fitness entries only, and the
  domestic Home > Maintenance group took the slot.
- **Date the data to the run.** The tablet donors' status bars have a date baked
  in, which is why the tablet framers are called with `show_date=False`; the
  completion history shows absolute dates and would otherwise contradict the
  device clock.

## Captions

Pattern, from the kit's design tokens: a tracked all-caps eyebrow in brand
green, then two Lora lines — warm white on top, green italic below, ending in a
period.

| Frame | Eyebrow | Lines |
| --- | --- | --- |
| dashboard | WHEN DID YOU LAST... | Everything you might forget, / *on one dashboard.* |
| history | THE WHOLE STORY | Every time you did it, / *and what you noted.* |
| People | THE OTHER HALF | The people you mean to call, / *before it's been a year.* |
| cadence | YOUR OWN RHYTHM | Every so often, / *however often that is.* |
| overdue | A NUDGE, NOT A NAG | It mentions what's slipped, / *then leaves you alone.* |
| tablet dashboard | THE BIG PICTURE | Every room, every rhythm, / *on one screen.* |

The kit's "avoid reusing *at a glance*" note is dayGLANCE's. For lastGLANCE the
phrase is the brand and is fine to use.
